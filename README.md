# Träningsschema för viktnedgång

Personlig HTML-app med:
- Veckoschema (styrka + crosstrainer)
- Illustrationer för styrkeövningar
- Vila-timer
- Veckochecklista (sparar i webbläsaren)

## Användning
Öppna `index.html` i webbläsaren.

## Illustrationer
För att illustrationerna ska synas: skapa mappen `imagine_images/` och lägg in dessa filer:
- NPLNt.jpg (Knäböj)
- PNlXB.jpg (Marklyft)

Aktivera Pages i Settings → Pages för att få en live-länk.
